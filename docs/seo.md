# SEO — MadnCo.

Built in: per-page title/description/canonical (`pageMetadata`), `metadataBase`
= www URL, static `public/og-image.png` (1200×630), `sitemap.xml`, `robots.txt`,
legal pages crawlable but `noindex`, `[...]` placeholders marked `data-nosnippet`.

## Vercel domains

- Primary: `www.madnco.frankjordan.dev`
- Add `madnco.frankjordan.dev` too and let it redirect to www, so typing the
  short address works.

## After launch

1. Search Console: add `www.madnco.frankjordan.dev` (or the `frankjordan.dev`
   domain property, which covers subdomains), submit `/sitemap.xml`.
2. Check the share preview by pasting the link into Discord, WhatsApp and a
   TikTok DM.
3. Put the site link in the @clipzhub06 bio, the Discord server description and
   the Twitch/YouTube "links" sections.
